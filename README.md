# TAGOPA 체험용 프로토타입

동탄–서울 광역버스(M4130·M4137)의 정류장·시간대별 승차 여유를 과거 기록으로 비교해 보는 **체험용 정적 웹**입니다.

- 이 프로젝트는 **비상업적인 학업·취업 포트폴리오용 시연**입니다. 자료 제공기관이 이 프로젝트를 승인·후원하거나 결과를 보증한 것이 아닙니다.
- 실제 현재 운행정보가 아닌 **시연용 예시**입니다. 예상값은 실제 탑승을 보장하지 않습니다.
- 출근·퇴근 체험의 도착정보는 **가상 예시**이며, 예상 승차 여유는 과거 기록 기반 시연용 추정입니다. 실시간 조회는 사용자가 직접 입력한 인증키로 공식 도착정보 API를 브라우저에서 호출하며, 키는 이 저장소·서버에 없습니다.
- 계산 방법과 자료 범위는 화면의 "설정·안내"에 있습니다.
- 이 저장소에는 화면에 필요한 대표 시간표 집계값만 있고, 날짜별 원본 도착·잔여석 기록과 원본 응답·배차표는 없습니다.
- **자료 출처(가공해서 사용)**
  - 승하차 인원 참고값: 경기도 공공데이터(공공데이터포털 '경기도_광역버스 버스노선별 정류장별 시간대별 일자별 승하차 인원', 이용허락범위 제한 없음).
  - 대표 시간표 집계: 경기버스정보(GBIS) 과거 도착정보를 가공한 시연용 자료입니다. 이용 조건은 별도로 확인 중입니다.
  - 배차 정보: 운수회사 배차표를 노선·차종 대응에 참고했습니다.
  - 자료 제공기관은 TAGOPA의 예상 결과와 무관하며 이를 보증하지 않습니다.
- 이 폴더는 개발 원본(TAGOPA)에서 `scripts/build_site.py`로 만든 배포 사본이며 직접 편집하지 않습니다.
